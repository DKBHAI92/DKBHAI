=====================================================
🎵 ROMANTIC BACKGROUND MUSIC GUIDE FOR SHRISHTI'S SITE 🎵
=====================================================

1. OUT-OF-THE-BOX MUSIC:
   The website comes with a built-in soothing Web Audio API 
   romantic chime / music-box synthesizer. Clicking the floating 
   music button (🎵) immediately plays a calm, magical romantic melody!

2. CUSTOM SONG / MP3 (OPTIONAL):
   If you want to play a custom romantic song (e.g. Ed Sheeran, Taylor Swift, 
   romantic instrumental, or a personalized voice note):
   - Simply copy your MP3 file into this folder (`assets/audio/`)
   - Rename it to: `romantic.mp3`
   - The website script will automatically detect and play your custom audio!
